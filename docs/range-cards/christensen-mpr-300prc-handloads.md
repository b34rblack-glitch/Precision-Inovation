# Christensen Arms MPR .300 PRC · handload starting profiles

Five load profiles, one per bullet, seated from the cartridge-base-to-ogive (CBTO) touch-the-lands measurements Jared took in this rifle in October 2026. Import file: `mpr-300prc-handloads.json` in this folder, generated by `scripts/write-loads-mpr-300prc.ts` from `scripts/loads-mpr-300prc.ts`.

## Adding it to the app

1. Settings → **Add from Backup** → pick `mpr-300prc-handloads.json`.
2. The sheet lists **5 loads not assigned to a rifle**. Tick that row and tap **Add 1 item**.
3. Open each new load, tap **Edit**, and pick **Christensen Arms MPR .300 PRC** under Rifle.

The loads travel unassigned on purpose: imported rows get fresh ids, so a file that carried the rifle would add a second MPR next to the one already in the app. If the app is empty, import `phoenix-workspace.json` first (it has the rifle), then add this file.

## What each profile holds

The readings are taken as the CBTO at which the bullet touches the lands. Each profile seats a conventional starting jump off that length; everything about the charge is left blank for the workup.

| Load | BC | Bullet length | Touch CBTO | Start jump | Seat to CBTO |
|---|---|---:|---:|---:|---:|
| Hornady ELD-X 212 gr | G7 .336 | 1.600 (estimate) | 2.931 | 0.020 | **2.911** |
| Barnes LRX 208 gr | G1 .633 | 1.819 (retailer, tip included) | 2.940 | 0.050 | **2.890** |
| Berger Elite Hunter 205 gr | G7 .324 | 1.487 | 2.949 | 0.020 | **2.929** |
| Nosler AccuBond LR 190 gr | G7 .301 | 1.460 | 2.949 | 0.020 | **2.929** |
| Hammer Hunter 214 gr | G7 .322 (Hammer's estimate) | 1.765 | 2.985 | 0.050 | **2.935** |

Jumps: Barnes recommends starting its monolithic LRX 0.050 in off the lands, and Hammer recommends jumping its bullets, so both start at 0.050 in; the jacketed bullets start at the usual 0.020 in. Bullet length only feeds the spin-drift estimate.

Every profile also records the bench: Hornady Match Grade full-length bushing sizer and seater (300 PRC 2-die set #544349) on a Hornady Lock-N-Load Iron Press. The bushing diameter is blank until one is chosen.

Twist check against the MPR's 1:8 barrel: Barnes and Hammer ask for 1:8.5 or faster, Berger for 1:11 minimum. All five are stable.

## Before trusting it

- Confirm the readings are touch-the-lands measurements (Hornady OAL gauge plus comparator), not seated rounds. If they were seated rounds, set each load's CBTO to the sheet value and clear the jump.
- Measure with the same .30 cal comparator insert the sheet was measured with; inserts differ by a few thousandths.
- Hammer's BC is an estimate and its listed weight is 213 gr; true the BC from drops.
- Barnes does not publish the 208 LRX length; the 1.819 in figure is a retailer's and includes the tip.
- Re-check touch every few hundred rounds as the throat wears, then update the loads (a load with range history versions itself on edit).
