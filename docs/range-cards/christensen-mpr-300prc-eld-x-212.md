## Before trusting it

- Chronograph the load and replace the published 2860 fps; rifles commonly run 20 to 60 fps off the test barrel, and this barrel is longer than the test barrel.
- Measure sight height (bore center to scope-tube center). 1.9" is an estimate built from the published ring height plus about 0.85" from bore to rail top.
- Confirm the 100 yd zero, then true muzzle velocity against impacts at 500 to 600 yd before relying on holds past that.
- Condition sets change air density only; the load's powder temperature sensitivity is not published and is not modeled.
